Accessibility

We build websites for other businesses to the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA, and this site follows the same standard.

What we check

Every page is tested with automated tools and by hand: keyboard navigation, screen reader labels, color contrast, text size and your device's reduced-motion setting. Animations stop when reduced motion is on.

Known limits

Pictures of our concept sites inside laptop and phone frames are decorative. Each one has a text description and a link to the live site, which you can use with a keyboard and screen reader. Some concept sites are in Russian.
